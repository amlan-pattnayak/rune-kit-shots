# rune-kit-shots

Renders every scene of the `kit-gallery` example in [Rune](https://github.com/anomalyco/rune)
(an MIT-licensed Rust UI framework by Anomaly) to images, in light and dark, on GitHub Actions.

Unofficial. This repo holds only a workflow and a script; Rune's code is checked out at a
pinned commit during the run. The images are for an unofficial component reference page.

Run it from the Actions tab ("Render"), then download the `shots` artifact.
